Varun Sai & Sowmya - Wedding Invitation Website
================================================
This folder is a complete static website (no build step, no login for visitors).

Deploy on Netlify (about 1 minute):
 1. Open https://app.netlify.com/drop
 2. Drag this whole folder (or the zip) onto the page.
 3. Netlify gives you a public https link. Share it on WhatsApp.
    (Sign in with Netlify to keep the site permanently; you can rename the link in Site settings.)

Deploy on Vercel: install the Vercel CLI, run `vercel --prod` inside this folder,
or drag the folder into https://vercel.com/new (after signing in).

Files: index.html (the site), assets/music.mp3, assets/fonts/*.woff2
